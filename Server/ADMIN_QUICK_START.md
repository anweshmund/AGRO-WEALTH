# 🚀 Quick Admin Setup

## Fastest Way to Create Admin Account

### Step 1: Create Admin User
```bash
cd Server
npm run create-admin
```

### Step 2: Login Credentials
- **Email:** `admin@agriwealth.com`
- **Password:** `admin123`
- **Role:** Admin

### Step 3: Login
1. Start your frontend: `cd Client && npm run dev`
2. Go to: `http://localhost:5173/login`
3. Select **"Admin"** role
4. Enter email and password above

### Step 4: Change Password
⚠️ **IMPORTANT:** Change the default password after first login!

---

## Alternative: Register via Frontend

1. Go to: `http://localhost:5173/signup?role=admin`
2. Fill in the form
3. Click "Create Account"
4. You're logged in as admin!

---

**That's it!** You now have admin access! 🎉
